Uniform installation

One marketplace, then one plugin.

Run these commands inside Claude Code. Adding the marketplace is a one-time user-level step.

Claude Code
/plugin marketplace add nikolareljin/claude-plugins

/plugin install claude-docsmith@nikolareljin-plugins
# or: claude-reposec / claude-reelsmith

/plugin
/reload-plugins

After installing, follow the product guide for companion CLI requirements and use the documented namespaced command. To refresh later, run /plugin marketplace update nikolareljin-plugins.
